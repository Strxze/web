📋 Steps followed
1.

Prepared the project folder

Created a folder containing index.html, style.css, and an img/ folder with images.

E:\For-Webdesigning\
2.

Initialized Git

Opened VS Code terminal and ran git init to start tracking the folder.

git init  →  git add .  →  git commit -m "initial commit"
3.

Created GitHub repository

Made a new public repository named "web" on GitHub with no README file.

github.com → New → Public → Create repository
4.

Generated a Personal Access Token

Created a token from GitHub Settings for authentication during push.

Settings → Developer Settings → Tokens (classic)
5.

Pushed files to GitHub

Connected the local folder to GitHub and uploaded all files.

git remote add origin https://TOKEN@github.com/Strxze/web.git
6.

Enabled GitHub Pages

Went to repository Settings → Pages → selected branch: main → saved.

Waited ~5 minutes → site went live
📌 Important notes

📄 index.html is must

GitHub Pages only serves the homepage if a file named exactly index.html exists in the root folder.

🔗 URL is case-sensitive

Repository name must match the URL exactly. Using lowercase avoids 404 errors.

🔒 Token expires

Personal access tokens expire. Generate a new one if you get authentication errors on push.
